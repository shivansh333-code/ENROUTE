# Himachal Road Journeys

A React + TypeScript + Vite frontend for exploring curated road journeys across Himachal Pradesh.

## Requirements
- Node.js 18 or newer
- npm

## Run locally
```bash
npm install
npm run dev
```
Vite will print a local URL (usually http://localhost:5173).

## Production build
```bash
npm run build
npm run preview
```

## Project structure
- `src/components/` — reusable interface components
- `src/views/` — page views
- `src/data/` — route and experience content
- `src/assets/images/` — images used by the frontend

This is a standalone React application. It does not require Google AI Studio or a Gemini API key.
